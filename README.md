# เตรียมสอบ (PrepCards)

เว็บแอปเตรียมสอบ: นำเข้าชีทเรียน สไลด์ หรือข้อสอบที่มีเฉลย (PDF, .docx, .pptx, .txt) แล้วแอปสร้างแฟลชการ์ดและแบบทดสอบให้
ใช้กฎดึงข้อความตายตัว ไม่ใช้ AI และไม่ส่งไฟล์ไปที่ใด ข้อมูลเก็บในเครื่องของผู้ใช้

- `index.html` คือแอปทั้งตัว (รวมไลบรารีอ่านไฟล์ไว้ในไฟล์เดียว) ใช้ออฟไลน์ได้หลังเปิดครั้งแรก
- `sw.js`, `manifest.webmanifest` ทำให้ติดตั้งลงหน้าจอโฮมและใช้แบบไม่มีเน็ตได้
- `source/` โค้ดต้นฉบับ สร้างใหม่ด้วย `npm i pdfjs-dist@3.11.174 mammoth@1.8.0 jszip@3.10.1 esbuild && node build.mjs` (ไฟล์ออกที่ `dist/pwa/`)
