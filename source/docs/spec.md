# PrepCards — สเปกเวอร์ชันแรก (2026-11-06)

## เป้าหมาย
เว็บแอปเตรียมสอบ ใช้ได้บนมือถือ/แท็บเล็ต/คอม ผู้ใช้อัปโหลดไฟล์ → เอนจินแบบกฎตายตัว (ไม่ใช้ AI) ดึงเนื้อหา → แฟลชการ์ด + แบบทดสอบ
เนื้อหามาจากไฟล์ของผู้ใช้เท่านั้น ต้องใช้งานได้ก่อนสอบวันที่ 9 พ.ย. 2569

## ขอบเขต
- รับไฟล์: .pdf (มีข้อความในตัว), .docx, .pptx, .txt/.md, วางข้อความ; จำกัด 50 MB/ไฟล์; ไม่มี OCR
- โครงสร้าง: วิชา → ชุดการ์ด (1 ไฟล์ = 1 ชุด) → การ์ด
- ชนิดการ์ด
  - `qa`: ข้อสอบที่ให้มาแค่คำถาม+คำตอบที่ถูก (เช่น "B ต้องสร้าง…")
  - `mcq`: ข้อสอบปรนัยมีตัวเลือกครบ + เฉลย (ตอบ/เฉลยท้ายข้อ หรือตารางเฉลยท้ายชุด) — ข้อที่ไม่มีเฉลยถูกข้าม
  - `term`: คำ : ความหมาย / คำ – ความหมาย / คำ = ความหมาย / X คือ Y / ตาราง 2 คอลัมน์
  - `list`: หัวข้อ (ชื่อสไลด์/heading) → รายการย่อย; สไลด์ติดกันที่ชื่อเดียวกันรวมเป็นใบเดียว
- ล้างข้อความ: ตัดหัวกระดาษ/เลขหน้าที่ซ้ำทุกหน้า, แก้ "ํา"→"ำ", รวมบรรทัดที่ขึ้นใหม่กลางประโยค, รวมข้อซ้ำ
- ติดธงให้ตรวจ: คำตอบแบบ "ถูกทุกข้อ/ผิดทุกข้อ/ข้อ ก และ ข" (ไม่มีความหมายถ้าไม่เห็นตัวเลือก)
- หน้าตรวจ: แก้/ลบ/เพิ่มการ์ด ก่อนบันทึก และแก้ภายหลังได้
- โหมดทบทวน
  - แฟลชการ์ด: แตะพลิก, จำได้/ยังไม่ได้, ใบที่ยังไม่ได้วนกลับในรอบเดียวกัน, เลือก "เฉพาะที่ยังไม่จำ"
  - ทำข้อสอบ: เลือกตอบ 4 ตัวเลือก; `mcq` ใช้ตัวเลือกจริง; `qa`/`term` ใช้คำตอบของการ์ดอื่นในชุด/วิชาเดียวกันเป็นตัวหลอก (ชนิดเดียวกัน: ตัวเลขกับตัวเลข), จบแล้วแสดงคะแนน + ทำเฉพาะข้อผิด
  - ทบทวนได้ระดับชุดหรือทั้งวิชา
- เก็บข้อมูล: ฐานข้อมูลของ artifact ใต้ `data/users/<id>/` (ส่วนตัว, ซิงก์ข้ามเครื่องเมื่อล็อกอินบัญชีเดียวกัน); fallback localStorage

## ไม่ทำในรอบนี้
OCR, AI, spaced repetition ข้ามวัน, cloze, แชร์ชุดการ์ด, .doc/.ppt แบบเก่า

## โครงสร้างโค้ด
- `src/normalize.js` ล้างข้อความไทย
- `src/readers.js` ไฟล์ → blocks (`{kind:'line'|'heading'|'table'|'slide', ...}`)
- `src/extract.js` blocks → cards
- `src/quiz.js` สร้างตัวเลือกหลอก, คิวแฟลชการ์ด
- `src/store.js` db/localStorage
- `src/app.js` + `src/style.css` UI
- `build.mjs` รวมเป็น `dist/index.html` ไฟล์เดียว (ไลบรารีจาก jsdelivr: pdfjs-dist 3.11.174, mammoth 1.8.0, jszip 3.10.1)
- `test/` เทสต์เอนจินด้วย node กับไฟล์จริง
